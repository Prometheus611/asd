Kliens oldali C szintaxisú szkript nyelv

  • böngésző értelmezi
  • Interaktivitást ad a weboldalhoz
    // dokumentum elérése, módosítása
    // hozzáférhető általa a weboldal és elemei (DOM)
  • módosítható vele a tartalom
  • módosítható az elemek stílusa
  • alkalmazható eseményeket kezelésére
  • űrlapadatok felhasználására

Szintaxis, konvenciók

  • Case sensitive
  • utasításokat pontosvesszővel kellett lezárni
    // mára már csak akkor, ha egy sorba többet írunk
  • white space
    // figyelmen kívül hagyja az utasításokban megjelenõ felesleges szóközöket, tabulátor és újsor karaktereket
  • komment
    // egysoros
    /*- több soros */

Változók

  • Nagybetű érzékenység
  • betűvel, vagy aláhúzással kezdődhet // továbbiakban tartalmazhat számot
  • nem egyezhet fenntartott szóval
  • deklarációk // var, let, const
  • Scope (érvényesség, láthatóság)
  • típus // dinamikus, automatikus, típuskonverziós metódusok (függvények)

Típusok

  • string // idézőjelek, aposztrófok (és backtick karakterek) között
  • number
  • boolean // true | false
  • undefined
  • null
  • objektum
  • metódus (függvény)
